# cdn-probe

проверяет, что cdn или прокси делает с запросами по пути к источнику. на источнике поднимается маленький сервер, через посредника гоняются пробы, и видно, что доехало, а что нет. только стандартная библиотека python.

## запуск

на источнике:
python3 probe/server.py --host 127.0.0.1 --port 9000

откуда угодно:
python3 probe/runner.py --through https://cdn.example.com/probe --direct https://origin.example.com/probe

сервер отражает запросы в ответе, держать только на время замеров. самотест без посредника запускается так:
python3 tests/selftest.py

## что проверяет

методы, тело get, буферизацию запроса, стриминг ответа, максимальный размер, обработку пути, кэш, таймаут простоя. подробности по пробам и разбор vk cloud cdn лежат в docs.
